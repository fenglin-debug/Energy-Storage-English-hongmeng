# 储能英语实战（鸿蒙基础版）

给做海外储能销售的人练英语用的手机软件。

- 不用注册，不用联网
- 学习记录只存在自己手机里
- 当前版本：0.4.1（基础版）

## 先看你的手机

### 纯血鸿蒙用户

受系统安装限制，无法直接安装程序包。可以告诉我你的华为账号，我使用官网 AGC，把你拉进测试组，邀请你使用。

请在本仓库 [Issues](https://github.com/fenglin-debug/Energy-Storage-English-hongmeng/issues) 发一条，写上你的华为账号（手机号或邮箱）。

收到邀请后，用同一华为账号登录手机，按提示安装即可。

### 非纯血鸿蒙用户

推荐直接安装安卓版，功能和内容与鸿蒙基础版一致，安装更简单：

打开 [安卓版最新下载页](https://github.com/fenglin-debug/energy-storage-English/releases/latest)，下载 `BESS-v0.4.1.apk`。

如果下载后后缀不是 `.apk`，请改名为 `BESS-v0.4.1.apk` 再安装。无病毒、无植入。

## 使用时请注意

- 软件完全离线，换手机需要自己导出、再导入学习记录。
- 卸载会删掉这台手机上的学习数据，换机或重装前先到「设置 → 学习记录备份」导出备份。
- 纯血鸿蒙请只通过我发给你的 AGC 测试邀请安装，不要装别人转发的安装包。

## 0.4.1 更新了什么

- 单词、例句和朗读按钮挨在一起，不用翻到页面底部。
- 背单词里去掉了「迁移运用」。
- 情景模拟点「显示原文」后，客户英文和中文一起出现。
- 内置 22 篇文章；文章播放支持循环、随机、自动下一篇，锁屏和耳机也能切歌。

要自己编译，见 [docs/DEVELOP.md](docs/DEVELOP.md)。
