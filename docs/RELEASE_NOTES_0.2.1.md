# BESS HarmonyOS 0.2.1

- 以 Android 0.2.0 Release 为产品基线，统一三入口导航、品牌图标、色板、页面层级和交互状态。
- 词汇改为“陌生 / 模糊 / 掌握”三档评价，并将评价提交与进入下一条分离。
- 场景补齐筛选、音频门槛、单向揭示、评分点、随机会话和完成分布。
- 文章支持 M4A、MP3、WAV 及 SRT/LRC 导入校验、稳定更新、整袋随机与固定播放器。
- 设置补齐双密码备份、恢复预览、语料差异确认、三档速度、本地提醒和脱敏诊断。
- 使用 AVSession 与音频连续任务提供后台、通知中心和锁屏媒体控制。
- 完全离线，不申请 INTERNET 或 MICROPHONE 权限，不使用 WebView。
