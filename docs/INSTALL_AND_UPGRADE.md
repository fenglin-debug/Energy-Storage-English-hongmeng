# BESS HarmonyOS 安装与升级

- 首次安装：使用维护者提供并已验签的 Release HAP/APP，核对应用名为“储能英语实战”，并用同目录 `SHA256SUMS.txt` 校验文件。
- 升级：使用同一发布证书签名的更高 `versionCode` 覆盖安装。不要卸载旧版、不要清除应用数据；覆盖升级会保留数据库、学习断点、文章进度和用户导入内容。
- 如果提示签名不一致，立即停止。该安装包不是同一正式证书签发的可升级版本，请联系维护者并提供本地诊断报告。
- 如果提示版本过低，不要降级。等待维护者发布更高 `versionCode` 的修复版。
- 卸载会删除应用沙盒中的数据库、导入文章和音频。卸载前必须在“设置 > 学习记录备份”导出 `.bessbackup`，并确认文件可被再次检查。
- Android、Windows 和 HarmonyOS 之间只通过用户主动选择的 `.bessbackup` 完整覆盖迁移；不会自动同步或合并。
