# BESS HarmonyOS 0.4.1

- 新增完整词库浏览，可按单词、释义和别名搜索，并按未学、学习中、已掌握、到期、收藏组合筛选。
- 新增收藏切换和词条详情；单词及每条例句均提供相邻的本地朗读按钮。
- 新词直接显示完整学习卡；复习词先回忆再显示答案，评价可反复修改，进入下一条时才提交一次复习记录。
- 停止生成“迁移运用”题型；旧学习断点中的 `TRANSFER` 继续按英译中显示。
- “掌握”作为界面标签保留，复习计划继续以 FSRS 到期时间为准，并自动修复旧版无限到期记录。
- 情景训练揭示原文后同步显示客户英文和中文；揭示前不创建隐藏文本组件。
- 内置两个文章包，共 22 篇文章；重复安装不会覆盖进度或用户导入内容。
- 文章播放器新增真实循环/随机队列、自动下一篇开关、上一篇/下一篇，以及通知中心、锁屏和耳机切歌。
- 播放页退出或应用进入后台后继续约每 5 秒保存进度，并在暂停、切换和播放完成时保存。
- 完全离线，不申请 INTERNET 或 MICROPHONE 权限，不使用 WebView。
