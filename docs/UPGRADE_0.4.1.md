# 升级到 BESS HarmonyOS 0.4.1

- Bundle ID 保持 `com.bess.salestrainer`，版本为 `0.4.1 / versionCode 5`。
- 请使用同一发布证书直接覆盖安装；不要卸载旧版，也不要清除应用数据。
- 数据库保持 schema 1，`.bessbackup v1` 的字段、顺序和加密方式均未改变，无需迁移备份文件。
- 首次启动 0.4.1 会幂等补装第二个内置文章包，内置文章总数为 22；既有文章进度和用户导入文章保留。
- 首次进入词汇功能时，会把旧版中“已复习但到期时间为无限大”的词和短语修复为立即到期，之后继续由 FSRS 排期。
- 旧断点中的 `TRANSFER` 题型仍可继续完成，但新复习不再生成该题型。
- 升级前仍建议在“设置 > 学习记录备份”导出并检查一份 `.bessbackup`。
- 如系统提示签名不一致或版本较低，请停止安装并核对安装包及 `SHA256SUMS.txt`。
