## 一、安装前提（先看这个！）

- ✅ 手机必须是**华为 HarmonyOS 手机**（鸿蒙系统；HarmonyOS NEXT 最佳）
- ❌ 苹果 iPhone、普通安卓手机（小米/OPPO/vivo 等）**装不了**这个格式
- ⚠️ 如果手机提示"禁止安装未知来源应用"，需要先开启：**设置 → 安全 → 更多安全设置 → 允许安装未知来源应用**

## 二、安装方法

1. 收到 `.hap` 文件后，用手机自带的**文件管理**找到它（一般在"下载"或"微信文件"里）
2. 点击这个文件 → 系统会弹出安装确认
3. 如果提示"该应用未经过应用市场验证"或"存在风险" → 点 **继续安装**
4. 等待安装完成，桌面会出现"储能英语实战"图标（蓝底闪电）

> 备选路径：把文件放到手机后，去 **设置 → 应用 → 应用管理 → 右上角"..." → 安装**，选择该文件。

## 三、使用必看（核心 5 条）

1. **完全离线，无需注册**
   这个 App 不联网、不需要账号，打开就能用，断网也能正常学习。

2. **学习记录只存在本机**
   单词进度、练习记录都存在手机本地，**卸载 App 或换手机之前，一定要先备份**。

3. **换机/卸载前：先导出备份**
   路径：**设置 → 学习记录备份 → 导出备份**
   会生成一个 `.bessbackup` 文件，请保存好（可转发给自己/网盘）。

4. **换机恢复：导入备份**
   新手机装好后：**设置 → 学习记录备份 → 恢复备份**，选择之前导出的 `.bessbackup` 即可找回全部学习记录。

5. **版本更新 = 先备份**
   更新到新版本如果提示要卸载旧版，**卸载会清空本地记录**——先导出备份再卸载，装好后恢复。

## 四、常见问题

| 问题 | 解决办法 |
|---|---|
| 点文件没反应 / 装不上 | 确认是华为鸿蒙手机；检查"允许未知来源应用"是否开启 |
| 提示"无法识别此文件" | 文件可能被压缩软件解压损坏，重新接收完整 .hap 文件 |
| 提示签名/证书问题 | 确认你拿到的是最新版 `fixed5` 文件（旧文件已过期） |
| 换了手机学习记录没了 | 用之前导出的 `.bessbackup` 在"恢复备份"里导入 |
| 忘记备份就卸载了 | 无法找回，只能重新学（所以一定先备份！） |
