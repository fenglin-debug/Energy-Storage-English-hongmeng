# BESS HarmonyOS 离线隐私说明

本应用完全离线运行，不创建账号，不连接服务器，不使用 WebView，不包含广告、遥测、远程日志、崩溃上报、在线更新或云同步。

本机保存的内容包括学习记忆、复习日志、任务和断点、播放设置，以及用户主动导入的语料、文章、音频和字幕。应用仅申请代理提醒权限，用于用户主动开启的每日学习提醒。

用户主动导出的 `.bessbackup` 只包含九类学习状态，不包含语料正文、音频、导入文章、文件路径、用户名或设备标识。使用密码时采用 PBKDF2-HMAC-SHA256（600,000 次）与 AES-256-GCM；密码不保存、无法找回。不加密导出时，任何取得文件的人都可能读取学习历史。

本地诊断报告只包含应用/系统/数据库/语料版本、架构、各学习表记录数量、最近备份时间和错误码，不包含学习正文、用户名、设备标识或文件路径。

卸载应用会删除系统应用沙盒内的数据。卸载前请先导出学习记录备份。
